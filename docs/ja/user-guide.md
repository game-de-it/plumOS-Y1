## 導入と復旧

必ず**Y1 Type A**用を使用してください。現在の候補は`plumOS-Y1-v0.10.24-TypeA.zip`です。公開ダウンロードはまだ案内していません。書き込み前に音楽・設定をバックアップし、復旧用に[メーカーサポート](https://www.innioasis.com/pages/support-details?type=y-1)の対応する純正Type A FWを確保してください。中断や失敗で起動不能になることがあります。

1. 本体を充電します。他の書き込みツールを閉じ、Y1の電源を切ってUSBを外します。
2. 対応するInnioasis UpdaterでY1／Type Aとファイルからのインストールを選び、パッケージZIPを指定します。
3. インストールを開始し、案内に従って電源OFFのY1をUSB接続します。
4. 完了表示までケーブルを抜かずに待ちます。完了後に外して起動します。
5. HOME選択が出た場合はY1 Theme Playerを選び、「常に使用」にします。

ロゴ版候補のscatterで書き込み対象なのは`LOGO`と`ANDROID`だけです。この手順では`PRELOADER`・`BOOTIMG`・`USRDATA`を有効にしないでください。データ保持やアップデーターのバージョンによる挙動差まで保証するものではありません。

復旧が必要な場合は、対応するWindows版SP Flash Toolの**Download Only**と純正パッケージの案内に従い、純正Type A FWへ戻します。Format AllやType B／Y2用イメージは使用しないでください。Type A実機の純正FWによる復旧実績はありますが、認識やドライバーはPC環境に依存します。

## 基本操作

Y1には回転ホイール・中央ボタン・上下左右を押せるリングがあります。タッチ画面や独立した音量キーはありません。

| 操作 | 動作 |
| --- | --- |
| ホイール回転 | カーソル移動。再生画面では操作アイコンを選択 |
| 中央 | 決定・開く・選択した操作を実行 |
| リング上／MENU | 前の画面へ戻る |
| リング下／再生・一時停止 | 再生・一時停止を切替 |
| 再生中にリング左右を短押し | 前曲・次曲 |
| 再生画面でリング左右を長押し | 巻き戻し・早送り。1秒の長押しで約10秒移動 |

再生画面では、再生・一時停止、音量−、音量＋、EQ、再生順のアイコンをホイールで選び、中央で実行します。Android設定やFMアプリではリング操作の意味が異なることがあります。Android設定はPCを接続せず、ホイールと中央ボタンで操作できます。

## ライブラリと音楽転送

USB公開される音楽ディスクの`Music`（`music`も可）に音楽を置きます。本体側の通常パスは`/storage/sdcard0/Music`です。これはY1内部のパスで、PC側のフォルダではありません。「アルバム」「曲」はスキャン済みの一覧を表示します。「ディレクトリ」はMusicを起点にサブフォルダへ移動できます。そこで曲を再生すると、**そのディレクトリ直下の音楽ファイルだけ**が再生対象になり、下位フォルダ内の曲は含みません。

1. USBを接続し、Y1の「設定 → USBファイル転送」を開きます。
2. USBストレージを開始します。共有中は再生を停止します。
3. FinderまたはWindows Explorerでディスクを開き、Musicに音楽をコピーします。ディスク名は環境により異なります。MTPアプリは不要です。
4. PC側でディスクを安全に取り出してから、Y1側でUSBストレージを終了します。
5. スキャン表示が終わってから追加曲を確認します。

通常のUSB接続だけでは純正のストレージ有効画面を開きません。開発用ADBが有効なので、信頼できるPCに接続してください。Finderにマウント済みディスクが見えない場合はサイドバー設定の確認やFinderの再起動を試します。共有終了後に音楽領域が戻らない場合は、まず安全な取り出しを行い、ケーブルを接続し直して再スキャンしてください。

スキャン対象の拡張子はMP3、M4A、AAC、FLAC、OGG、WAV、AIF／AIFF／AIFC、WMA、APE、OPUS、WV、MKA、ALAC、CAFです。実際の再生可否はコンテナ・コーデックとAndroid／LibVLCのデコーダーに依存し、拡張子の認識だけで全ファイルの再生を保証するものではありません。

設定で一覧表示をファイル名／タグ内の曲名から選べます。タイトルタグが空の場合、再生画面は拡張子を含むファイル名を表示します。長い文字列はスクロールし、日本語など主フォントにない文字は別フォントで補います。

## ADBを使わないアプリ更新

0.10.24への初回導入・旧開発FWからの更新はFW ZIPを適用してください。APKだけではシステム領域の共有ライブラリは更新されません。その後のプレイヤー単体更新は下記の手順で行います。


FW一式の導入後、次回以降のプレイヤー単体更新は本体から実施できます。

1. USBストレージを開始し、音楽ディスクのMusicと並ぶ`Updates`フォルダに`plumOS-Y1-v0.10.24-player.apk`をコピーします。フォルダがなければ作成してください。
2. PCで安全に取り出してから、Y1でUSBストレージを終了します。
3. 「設定 → アプリを更新」を開きます。Updatesがあれば最初に開き、別のフォルダも参照できます。
4. ホイールと中央ボタンでAPKを選び、ファイル名と更新前後のバージョンを確認して「インストール」を選びます。
5. 更新中の画面で電源を切らずに待ちます。完了後にプレイヤーが再起動し、アプリ設定を引き継ぎます。

選んだファイルは内部領域へコピーして確認します。システムのインストールAPIで内部領域を明示的に指定し、純正の保存先選択ダイアログは使いません。このプレイヤーと同じアプリID・署名のAPKだけを受け付け、古いバージョンコードは拒否します。同じ版の再インストールも可能です。設定・追加テーマを保持する上書き更新で、FW・起動ロゴ・ホイール設定は変更しません。先にアンインストールする必要はありません。ADBやネット接続は不要です。APKは256 MiBまでで、内部領域の空き容量も必要です。

## スキャンとキャッシュ

保存済みの曲情報を先に表示します。裏でファイル一覧の確認は行いますが、タグを読み直すのは追加された曲やサイズ・更新日時が変わった曲だけです。削除された曲はスキャン完了後に一覧から除きます。音楽領域が利用できない場合に保存済みキャッシュを消す動作にはしていません。スキャン中もホイール操作できます。

- 「音楽再スキャン」：キャッシュを再利用して変更を確認。
- 「キャッシュ削除・再構築」：曲情報のキャッシュを消し、タグを読み直す。音楽ファイル・テーマ・EQ設定は削除しません。

初回や再構築は時間がかかります。サイズと更新日時が両方変わらないタグ編集は差分検出できないため、再構築を使ってください。所要時間はファイル数やストレージ速度に依存します。

## 音量・EQ・設定

再生順は順番・全曲リピート・1曲リピート・シャッフルです。10バンドEQはプリセットとカスタムに対応します。カスタムでは帯域を選び、中央で編集モードにしてホイールで1 dBずつ調整します。EQ設定は保存されます。帯域を強調した際の自動ゲイン低下は行わないため、強いブーストでは音割れすることがあります。

通常音量は0〜13です。赤字の`14/13`・`15/13`・`16/13`はソフトウェア音量110%・120%・130%です。ピークが音割れする場合があります。ブーストはアプリ再起動後には保持せず、出力先の変更でも解除します。

設定には、確認付きシャットダウン、タイマーOFF／10／20／30／60／90／120分、画面タイムアウト、クリック音、バイブ、輝度、Bluetooth設定、FMラジオ、Android設定、日付・時刻・24時間表示、容量、日本語／英語、エアプレーンモード、USB転送、スキャンとキャッシュがあります。アプリの言語設定は曲タグの翻訳やAndroid全体の言語変更は行いません。

BluetoothはAndroidのペアリング・接続画面を開きます。ペアリング済みで無音の場合は、そこでメディア音声接続を確認してください。FMは内蔵MediaTekラジオアプリを起動します。エアプレーンモードをOFFにし、アンテナ用の有線イヤホンを接続してください。


### 設定項目の順序

関連する項目を隣接させています。ファイル名／タグ表示とライブラリ管理、クリック音とバイブ、輝度・タイムアウト・言語、USB転送・アプリ更新・容量・Bluetooth・エアプレーンモード・FM、日付と時刻・Android設定・電源タイマー・シャットダウンの順です。更新時も保存済みの設定値を維持します。

## 既知の制限

- 純正フロントエンドは無効で、音楽以外の機能をすべて再実装したわけではありません。
- USB切替・シャットダウン・一部設定にはFWで付与するシステム権限が必要です。
- スピーカーと有線イヤホンで、曲中の異なる位置に断続的なノイズを確認しています。同様のBluetooth試聴では報告されていませんが、原因は未確定です。
- 再生確認は、ビットパーフェクト出力・DACのハイレゾ動作・すべての音源形式やヘッドホンとの互換性の証明ではありません。

不具合報告には、アプリ／FWバージョン、Type Aであること、出力先、形式、再現手順、再スキャン・再起動による変化を添えてください。公開するログ・画像から個人パス、シリアル番号、私的な曲名やジャケットを除いてください。
