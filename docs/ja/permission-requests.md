## Innioasis／ベンダー権利

件名：Y1 Type A改造FWの再配布許諾とOSS対応ソースについて

純正Y1 Type A FW 3.1.2を基に、無償コミュニティ音楽プレイヤーFW「plumOS-Y1」の公開を準備しています。ベンダーソフトと表記を保持した加工済みsystemイメージ・起動ロゴ等をGitHubで公開するにあたり、権利者による改造・再梱包・第三者への再配布が許諾されるか、必要な表記・条件・除外対象を教えてください。純正ネイティブ依存物や、同梱する場合のkernelを含め、GPL／LGPL部分の対応ソース公開先または有効な提供条件も確認したいです。回答には供給元コンポーネントの再配布権限も含まれますか。公開前に正確なファイル・パーティション一覧を提示可能です。

[公式規約](https://www.innioasis.com/policies/terms-of-service)の窓口を使い、回答者の権限も確認します。コミュニティでの公開例だけでは代替しません。

## 旧Winamp標準スキン画像

件名：別プレイヤーでのWinamp 2.91標準スキン画像の加工・再配布について

独立した携帯音楽プレイヤー用フロントエンドを準備しています。ローカル試作品では、Webampのbase-2.91.wszに収録されたWinamp 2.91標準画像を抽出・加工したPNGを使用しています。Winampアプリ自体の再配布ではありません。この画像の許諾権限を持つ主体と、複製・抽出・リサイズ等の改変、Winamp以外への組込み、ソース／バイナリと説明用画面例の公開が認められるかを教えてください。必要な表記、名称・商標、ホスティング、商用／非商用その他の条件、または許諾対象外であることを確認したいです。Webampのコード用MITライセンスとは分けて確認しています。

[Winamp公式サポート](https://support.winamp.com/)を入口とし、別主体の権利をWebampメンテナーが許諾できるとは仮定しません。

## VideoLAN：配布物のライセンス・対応ソース確認

件名：libvlc-all 3.7.1 ARMv7のライセンスとソース対応について

Mavenのorg.videolan.android:libvlc-all:3.7.1（AAR SHA-256 bc1e14d4344c90e4931ad524671024e9605d599d8ca22a894f709e3c0887fb48）を確認しています。POMにはLGPL 2.1とありますが、ARMv7のlibvlc.soにはdvdcss_open／dvdcss_read・DVDOpenの定義があり、リリース用レシピには既定のGPL有効モードがあります。この特定のネイティブ結合物に適用されるライセンス、完全な対応ソース・構成・依存物表記、公式のLGPL 2.1限定API 17／ARMv7配布物の有無を確認したいです。公開ライセンスが既に与える配布権の例外許可を求めるのではなく、実際のビルドに適用される条件を特定するための質問です。
