# リリース準備 — 0.10.24

[English](../en/release.md) | [配布根拠](distribution-review.md) | [最終試験](release-validation.md)

2026-11-18。初回公開候補は0.10.24／versionCode 46、Y1 Type A専用です。0.10.22は復旧・比較用に維持します。公開先は[GitHub Releases](https://github.com/game-de-it/plumOS-Y1/releases/tag/v0.10.24)です。

PLUMOSAMPの必要な領域と新しい桃のドット絵を組み込み、元の稲妻・スローガン・未使用シート・カーソル・解説文を除外します。テーマIDは既存設定のためwinampを維持し、表示名はPLUMOSAMPです。音声処理・再ビルド済みLibVLC・ホイール／USB修正・権限・起動ロゴは維持します。


今回の更新は英語USB画面の「戻る」を「Back」にする翻訳と版情報のみです。0.10.23の全実機試験を保持し、0.10.24ではAPKの英日表示を確認します。新しい0.10.24 FWの再書込みは未実施として記録し、過去の試験結果を置き換えません。

Type A FW ZIP、同一署名のプレイヤーAPK、アプリソース、対応するLibVLCソース、導入中心の英語・日本語・併記リリース原稿、検証状態、MIT LICENSE、部品表記、マニフェスト、SHA256SUMSをまとめます。ネイティブはバイトを変更しないため対応ソースの内容も維持します。
