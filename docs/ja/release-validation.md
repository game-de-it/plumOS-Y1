# 実機検証と変更範囲 — 0.10.24

[English](../en/release-validation.md)

2026-11-18。0.10.24／versionCode 46は、USB画面の「戻る」を英語表示で「Back」にする翻訳修正です。日本語表示は維持します。配布先は[GitHub Releases](https://github.com/game-de-it/plumOS-Y1/releases/tag/v0.10.24)です。

## 今回の確認

- 署名済み0.10.24 APKをY1へ導入し、実際のUSB画面で英語「Back」・日本語「戻る」を確認。元の言語設定へ戻しました。共有のON/OFFはこの表示検査では実行していません。
- Java 55クラスの比較で変更はUiText.classのみ。APKの変更はクラスのDEXと版情報のみで、音声・USB制御・ホイール処理、画像、ネイティブを維持します。
- FWのAPK／ネイティブを抽出照合し、e2fsckに合格。書込み対象と他のパーティションを維持します。
- FW SHA-256：`1acc8ba8e4c88d04ed67eef5a6555887d834866c8fb62864565347cfcd324902`
- APK SHA-256：`8c2d6e19ff49c45f84f12cf31030c91903e52651a5a3a844a7513de6e7ebf0dd`

## 引き継ぐ実機証跡

[0.10.23の全実機記録](validation-v0.10.23.md)を版・ハッシュ付きで保持しています。39条件の形式／EQ、MP3/M4A両エンジン、Bluetooth／スピーカー、USB転送と共有終了、本体APK更新、単体操作、クリック／バイブ、シャットダウン／再起動は0.10.23で確認済みです。今回の0.10.24 FWを再書込みした結果ではありません。0.10.24はAPKの表示確認とFWの組立検査を行い、FWの再書込み・コールドブートは未実施です。
