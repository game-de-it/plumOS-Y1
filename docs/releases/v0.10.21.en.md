# plumOS-Y1 v0.10.21 — First release

**Innioasis Y1 Type A only.** Based on original firmware 3.1.2 / Android 4.2.2. Type B and Y2 are not supported by this package.

This first release provides a wheel-operated music frontend, ten themes, USB disk transfer, and on-device player updates. Start with the firmware ZIP for a first installation. The APK alone is not a replacement for the firmware.

## 1. Choose the correct download

| File | Use |
| --- | --- |
| `plumOS-Y1-v0.10.21-TypeA.zip` | **First installation:** firmware with the player, wheel mapping, required system permissions, and plumOS boot logo |
| `plumOS-Y1-v0.10.21-player.apk` | **Later player updates:** for a Y1 already running compatible plumOS-Y1 firmware |
| `plumOS-Y1-v0.10.21-source.tar.gz` | Player source, build helpers, fonts/notices, and documentation; not a flashable image |
| `SHA256SUMS` | Checksums for the release files |

The source archive does not include a stock firmware base, music, signing keys, or device logs. See the supplied notices for the separate conditions of vendor firmware and third-party components.

## 2. Before installing

- Confirm that the player is **Y1 Type A**. If its type is unknown, check the device-type information in the [Updater guide](https://innioasis.app/guide.html) before flashing; an already changed firmware version alone does not establish hardware type.
- Back up music and other personal files. Keep matching original Type A firmware available for recovery.
- Charge the player and use a reliable USB data cable. Close other firmware-writing utilities.
- Get [Innioasis Updater CE](https://innioasis.app/). Its upstream guide covers Windows, macOS, and Linux setup and drivers. The project has not independently verified first installation on every host platform.
- Fully power the player off; turning the display off is not sufficient. Disconnect USB until the updater asks for it.

This writes internal firmware. An interrupted or incorrect flash can prevent booting. The supplied scatter selects LOGO and ANDROID; it does not select user data. Back up anyway, and do not enable additional partitions or formatting options.

## 3. First installation with Updater CE

1. Download `plumOS-Y1-v0.10.21-TypeA.zip` and `SHA256SUMS` from the release assets.
2. Verify the ZIP checksum using the commands below. **Keep the firmware as a ZIP** for the updater's file-install option.
3. Open Updater CE and select **Innioasis → Y1 → Type A** where the controls are available.
4. Choose the option to **install from a file**, and select the firmware ZIP. Do not select the APK or source archive.
5. Start **Install / Restore**. When prompted, connect the **powered-off** Y1 by USB.
6. Wait until the updater explicitly reports completion. Keep the cable connected and power stable throughout writing.
7. After completion, disconnect USB and start the player by holding its center button.
8. If Android asks for a Home app, select **Y1 Theme Player → Always**. The plumOS logo and player home screen should appear.

Menu wording can vary by updater version. Follow its connection prompts rather than repeatedly disconnecting during writing. If the device is not detected, first use the platform-specific steps in the [Updater guide](https://innioasis.app/guide.html).

### Verify the firmware download

macOS:

```sh
shasum -a 256 plumOS-Y1-v0.10.21-TypeA.zip
```

Linux:

```sh
sha256sum plumOS-Y1-v0.10.21-TypeA.zip
```

Windows PowerShell:

```powershell
Get-FileHash .\plumOS-Y1-v0.10.21-TypeA.zip -Algorithm SHA256
```

Expected firmware SHA-256:

```text
e88deceb5fc453474536687d872c7951b15b0e10252330536af69cf492419da3
```

If all listed release files have been downloaded, `shasum -a 256 -c SHA256SUMS` (macOS) or `sha256sum -c SHA256SUMS` (Linux) verifies the entire set.

## 4. Copy music and play

1. Connect USB. On Y1, open **Settings → USB file transfer → Turn on USB storage**.
2. Open the exported disk in Finder or Windows Explorer. Its name may vary.
3. Put music under **Music** at the disk root. Subfolders are supported; `music` is also accepted.
4. Safely eject the disk on the computer, then choose **Turn off USB storage** on Y1.
5. Let the background scan finish, then select **Songs**, **Albums**, or **Directories**.

Rotate the wheel to select; press Center to confirm. Upper ring/MENU goes back, lower ring toggles playback, and the left/right ring skips tracks. On the playback screen, holding left/right seeks at approximately ten seconds per second held. Volume uses the playback screen's volume icons; there are no dedicated volume keys or touchscreen.

Directory playback queues only music directly inside the selected folder. Japanese names, long-text scrolling, filename/tag-title display, and a metadata cache are supported. The first scan or a cache rebuild takes longer than an incremental scan.

## 5. Later app updates — no ADB needed

Once firmware 0.10.21 or later with the installation permission is installed:

1. Start USB storage and copy the matching player APK into **Updates** beside Music. Create Updates if necessary.
2. Eject on the computer, then end USB sharing on Y1.
3. Open **Settings → Update player**. Select the APK with the wheel and Center.
4. Check its filename and current/new version, then choose **Install**.
5. Wait without switching off. The player returns automatically after installation.

Settings and added themes are retained. The player checks package identity, signing certificate, and version code. Older versions and unrelated or differently signed APKs are rejected; same-version reinstall is supported. This updates the app, not the firmware or boot logo. Do not uninstall first.

## 6. Recovery and troubleshooting

- **Wrong hardware type or uncertain model:** stop and confirm it before flashing. Do not try this package on Type B or Y2.
- **Black screen or interrupted installation:** use Updater CE's original-software restoration for the matching Y1 Type A, following the [recovery/setup guide](https://innioasis.app/guide.html). Compatible Windows SP Flash Tool recovery with original Type A firmware has also been demonstrated. Follow the original package's Download Only instructions; avoid Format All and do not enable extra partitions on this custom package.
- **Disk missing in Finder:** check Finder's external-disk sidebar setting or relaunch Finder, and confirm USB storage was started on Y1.
- **New music missing:** end USB sharing, wait for scanning, then use Music rescan. Use Clear/rebuild cache for tag changes that keep the same size and timestamp; it does not delete music.
- **Update needs compatible firmware:** install the full firmware first; an APK on an older system does not add its system permissions.
- **Bluetooth paired but silent:** open Bluetooth settings and confirm the media-audio connection.

## Included and known limits

- Ten music-player themes, English/Japanese menus and fallback fonts; native Android/LibVLC playback, EQ, repeat/shuffle, directory browsing, and library cache.
- Brightness, click/vibration, Android/Bluetooth/date settings, FM access, shutdown, and a shutdown timer. FM needs airplane mode off and wired earphones as an antenna.
- The stock frontend is disabled. Its photo, e-book, calculator, and calendar features are not reproduced.
- Intermittent pops remain reported on speaker/wired output; the cause is unconfirmed. Equivalent Bluetooth listening did not show the issue in the reported tests.
- EQ/volume boosts can clip. Recognizing an extension does not guarantee every codec/container variant will play.
- ADB is enabled for development; connect to trusted computers. Ordinary transfer and app updates do not require a PC ADB installation.
