# plumOS-Y1 v0.10.24 — 初回リリース

**Innioasis Y1 Type A専用です。** 純正FW 3.1.2／Android 4.2.2をベースにしています。Type B・Y2は対象外です。

ホイール操作の音楽フロントエンド、10テーマ、USBディスク転送、本体からのアプリ更新をまとめた初回版です。初回導入と旧開発FWからこの版への更新はFW ZIPを使用してください。APKだけではFWの代わりになりません。

## 2. 導入前の準備

- 本体が**Y1 Type A**であることを確認します。不明な場合は[Updaterのガイド](https://innioasis.app/guide.html)のタイプ説明を確認し、推測で書き込まないでください。改造後のFWバージョンだけではハードのタイプを判断できません。
- 音楽などの個人ファイルをバックアップし、復旧用の対応する純正Type A FWを確保します。
- 本体を充電し、安定したUSBデータケーブルを使います。他のFW書き込みツールは閉じてください。
- [Innioasis Updater CE](https://innioasis.app/)を用意します。Windows・macOS・Linuxの導入とドライバーは配布元のガイドを参照してください。本プロジェクトで全ホスト環境の初回導入を個別に検証したわけではありません。
- 本体の電源を完全に切り、Updaterの案内までUSBを外しておきます。画面が消えているだけの状態とは異なります。

本体内蔵FWを書き換えます。中断や誤ったファイルの適用で起動不能になる場合があります。本パッケージのscatterはLOGOとANDROIDだけを選択し、ユーザーデータ領域は選択していませんが、事前バックアップは行ってください。書き込み対象の追加やフォーマット設定の変更はしないでください。

## 3. Updater CEから初回インストール

1. リリースの配布ファイルから`plumOS-Y1-v0.10.24-TypeA.zip`と`SHA256SUMS`をダウンロードします。
2. 下記の方法でZIPのチェックサムを確認します。Updaterのファイル指定には**ZIPのまま**使用します。
3. Updater CEを開き、項目が表示される場合は**Innioasis → Y1 → Type A**を選びます。
4. **ファイルからインストール**する項目でFWのZIPを指定します。APKやソースアーカイブは指定しません。
5. **インストール／復元（Install / Restore）**を開始し、案内が出たら**電源OFFのY1**をUSB接続します。
6. Updaterが完了を明示するまで待ちます。書き込み中はケーブルを抜かず、電源を安定させてください。
7. 完了後にUSBを外し、中央ボタンを長押しして起動します。
8. AndroidのHOME選択が出た場合は**Y1 Theme Player → 常に使用**を選びます。plumOSのロゴとプレイヤーのホーム画面が表示されます。

項目名はUpdaterの版により異なる場合があります。接続は画面の案内に従い、書き込み中に抜き差ししないでください。認識しない場合は、まず[Updaterガイド](https://innioasis.app/guide.html)のOS別手順を確認してください。

### ダウンロードしたFWのチェックサム確認

macOS:

```sh
shasum -a 256 plumOS-Y1-v0.10.24-TypeA.zip
```

Linux:

```sh
sha256sum plumOS-Y1-v0.10.24-TypeA.zip
```

Windows PowerShell:

```powershell
Get-FileHash .\plumOS-Y1-v0.10.24-TypeA.zip -Algorithm SHA256
```

FWの期待SHA-256:

```text
1acc8ba8e4c88d04ed67eef5a6555887d834866c8fb62864565347cfcd324902
```

記載された配布ファイルをすべて取得した場合は、macOSの`shasum -a 256 -c SHA256SUMS`、Linuxの`sha256sum -c SHA256SUMS`で一括確認できます。

## 4. 音楽を転送して再生

1. USB接続し、Y1の**設定 → USBファイル転送 → USBストレージを開始**を選びます。
2. Finder／Windows Explorerで公開されたディスクを開きます。ディスク名は環境によって異なります。
3. ディスク直下の**Music**へ音楽をコピーします。サブフォルダも使用でき、`music`という名前も認識します。
4. PCで安全に取り出してから、Y1で**USBストレージを終了**します。
5. バックグラウンドのスキャンを待ち、**曲・アルバム・ディレクトリ**から選曲します。

ホイールで移動、中央ボタンで決定です。リング上／MENUで戻り、下で再生・一時停止、左右で前曲・次曲へ移動します。再生画面で左右を長押しすると、1秒の長押しで約10秒の早送り・巻き戻しになります。音量は再生画面の音量アイコンで変更します。タッチ画面や独立した音量キーはありません。

ディレクトリ再生の対象は、選んだフォルダ直下の曲だけです。日本語名、長い文字列のスクロール、ファイル名／タグ表示、曲情報キャッシュに対応します。初回や再構築は差分スキャンより時間がかかります。

## 5. 次回以降のアプリ更新 — ADB不要

更新権限を持つ0.10.24以降のFWを導入済みなら、次の方法で更新できます。

1. USBストレージを開始し、Musicと並ぶ**Updates**に対応するプレイヤーAPKをコピーします。Updatesがなければ作成します。
2. PCで安全に取り出し、Y1でUSB共有を終了します。
3. **設定 → アプリを更新**を開き、ホイールと中央ボタンでAPKを選びます。
4. ファイル名と更新前後のバージョンを確認し、**インストール**を選びます。
5. 電源を切らずに待ちます。完了後はプレイヤーが自動で起動し直します。

設定・追加テーマは保持します。アプリID・署名・バージョンコードを確認し、旧版・別アプリ・署名違いは拒否します。同じ版の再インストールも可能です。更新するのはアプリだけで、FWや起動ロゴは変更しません。先にアンインストールする必要はありません。

## 6. 復旧・困ったとき

- **タイプや機種が不明**：書き込み前に確認してください。Type B・Y2へこのパッケージを試さないでください。
- **真っ暗・書き込み中断**：[復旧・導入ガイド](https://innioasis.app/guide.html)に従い、Updater CEの純正ソフトウェア復元から対応するY1 Type A FWへ戻します。対応するWindows版SP Flash Toolと純正Type A FWによる復旧実績もあります。純正パッケージのDownload Only手順に従い、Format Allや本カスタムパッケージでの対象領域の追加は避けてください。
- **Finderにディスクが出ない**：外部ディスクのサイドバー表示設定やFinder再起動を確認し、Y1側でUSBストレージが開始されているか確認します。
- **追加曲が出ない**：USB共有を終了してスキャンを待ち、必要なら音楽再スキャンを実行します。サイズ・更新日時が変わらないタグ変更にはキャッシュ再構築を使います。音楽ファイルは削除しません。
- **更新に対応FWが必要と出る**：先にFW一式を導入してください。旧FWへのAPK追加だけではシステム権限は付きません。
- **Bluetoothがペアリング済みなのに無音**：Bluetooth設定でメディア音声の接続を確認します。

## 主な機能と制限

- 10種類のテーマ、日本語・英語とフォント補完、Android／LibVLC再生、EQ、リピート／シャッフル、ディレクトリ再生、キャッシュ。
- 輝度、クリック音・バイブ、Android／Bluetooth／日時設定、FM呼び出し、シャットダウンとタイマー。FMにはエアプレーンモードOFFとアンテナ用の有線イヤホンが必要です。
- 純正フロントエンドは無効化します。写真・電子書籍・電卓・カレンダーは再実装していません。
- スピーカー・有線出力の断続的なノイズは未解決で、原因は未確定です。同様のBluetooth試聴では報告されていません。
- EQや音量ブーストは音割れする場合があります。拡張子の認識が、全コーデック・全コンテナの再生保証を意味するわけではありません。
- 開発用ADBは有効です。信頼できるPCに接続してください。通常のファイル転送・アプリ更新にPCのADB導入は不要です。
