# plumOS-Y1 v0.10.26 — Player update

[日本語](v0.10.26.ja.md) · [First-installation guide](v0.10.24.en.md)

**Y1 Type A with plumOS-Y1 v0.10.24 already installed:** download `plumOS-Y1-v0.10.26-player.apk`. This release changes the player app only. Keep the installed firmware; no flash or PC ADB is required.

1. In the player, choose **Settings → USB file transfer → Turn on USB storage**.
2. Copy the APK into `Updates` on the music disk using Finder or Windows Explorer.
3. Eject the disk on the computer, then turn off USB storage on Y1.
4. Choose **Settings → Update player**, select the APK, and confirm installation. Do not uninstall the existing player.
5. Check that the player opens and your music and settings remain available.

**First installation:** use the [v0.10.24 Type A firmware ZIP](https://github.com/game-de-it/plumOS-Y1/releases/tag/v0.10.24), then apply this APK. Do not use the Y1 package on Type B or Y2.

Changes since v0.10.24: dedicated A-B repeat while retaining Y1's on-screen volume buttons; accelerated hold-to-seek; fuller lists and cursor-first scrolling; direct directory browsing while the library scan runs; and temporary status messages that restore the normal display. The ten themes, EQ, audio libraries, USB switching, boot image and firmware configuration are unchanged.

The v0.10.24 [LibVLC source package](https://github.com/game-de-it/plumOS-Y1/releases/tag/v0.10.24) still matches this APK's native libraries. Source changes for this app update are in this repository at tag `v0.10.26`.
