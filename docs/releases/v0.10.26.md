# plumOS-Y1 v0.10.26 — Player update / アプリ更新

## English

**For Y1 Type A already running plumOS-Y1 v0.10.24:** download `plumOS-Y1-v0.10.26-player.apk`. Copy it to `Updates` on the Y1 music disk, eject the disk, end USB storage mode, then select **Settings → Update player** on the device. Do not uninstall the existing player. No firmware flash or PC ADB is needed.

**First installation:** install the [v0.10.24 Type A firmware ZIP](https://github.com/game-de-it/plumOS-Y1/releases/tag/v0.10.24) with Innioasis Updater CE, then apply this APK. The APK alone cannot install plumOS on stock firmware. Type B and Y2 are unsupported.

This update adds A-B repeat, faster long-hold seeking, fuller song lists, cursor-first scrolling, direct directory browsing during scans, and corrected temporary messages. Y1's on-screen volume controls remain. See the [English update guide](https://github.com/game-de-it/plumOS-Y1/blob/v0.10.26/docs/releases/v0.10.26.en.md).

## 日本語

**plumOS-Y1 v0.10.24導入済みのY1 Type A:** `plumOS-Y1-v0.10.26-player.apk`をダウンロードします。Y1の音楽ディスクの`Updates`へコピーし、PCで取り出してUSBストレージを終了後、本体の**設定 → アプリを更新**から選択してください。既存アプリはアンインストールしないでください。FWの再書き込みやPC側のADBは不要です。

**初回導入:** Innioasis Updater CEで[v0.10.24のType A用FW ZIP](https://github.com/game-de-it/plumOS-Y1/releases/tag/v0.10.24)を適用してから、このAPKで更新します。純正FWにAPKだけを適用してもplumOSにはなりません。Type BとY2には使用できません。

今回の更新は、A-Bリピート、長押しシークの加速、曲一覧の表示行とカーソル移動、スキャン中のディレクトリ表示、一時通知の復帰を追加・修正します。Y1の画面内音量ボタンは維持しています。[日本語の更新手順](https://github.com/game-de-it/plumOS-Y1/blob/v0.10.26/docs/releases/v0.10.26.ja.md)も参照してください。

The native LibVLC libraries are unchanged from v0.10.24; the matching source package remains available in [v0.10.24 assets](https://github.com/game-de-it/plumOS-Y1/releases/tag/v0.10.24). The app source is at tag `v0.10.26`. Checksums are in `SHA256SUMS`.
