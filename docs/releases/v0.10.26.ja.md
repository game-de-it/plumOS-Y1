# plumOS-Y1 v0.10.26 — アプリ更新

[English](v0.10.26.en.md) · [初回導入手順](v0.10.24.ja.md)

**plumOS-Y1 v0.10.24導入済みのY1 Type A:** `plumOS-Y1-v0.10.26-player.apk`を使用してください。今回はアプリだけの更新です。FWの再書き込みやPC側のADBは不要です。

1. 本体で**設定 → USBファイル転送 → USBストレージを開始**を選びます。
2. FinderまたはWindows Explorerで音楽ディスクの`Updates`へAPKをコピーします。
3. PCでディスクを取り出し、本体でUSBストレージを終了します。
4. **設定 → アプリを更新**からAPKを選び、インストールを確定します。既存アプリはアンインストールしないでください。
5. アプリが起動し、音楽と設定が残っていることを確認します。

**初回導入:** [v0.10.24のType A用FW ZIP](https://github.com/game-de-it/plumOS-Y1/releases/tag/v0.10.24)を導入してから、このAPKを適用します。Type BやY2には使用しないでください。

主な変更: Y1の画面内音量ボタンを残したA-Bリピート、長押しシークの段階的な加速、曲一覧の表示範囲とカーソル移動、全体スキャン中のディレクトリ表示、通知表示後に元の画面へ戻る処理。10テーマ、EQ、音声ライブラリ、USB切替、起動画像、FW設定は変更していません。

ネイティブライブラリに対応するLibVLCソースは[v0.10.24の配布物](https://github.com/game-de-it/plumOS-Y1/releases/tag/v0.10.24)を参照してください。今回のアプリの変更ソースは本リポジトリの`v0.10.26`タグに含みます。
