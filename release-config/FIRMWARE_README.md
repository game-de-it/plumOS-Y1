# plumOS-Y1 v0.10.24 — Y1 Type A

## English

Music-player firmware for Innioasis Y1 Type A, based on stock 3.1.2 / Android 4.2.2. Do not use on Type B or Y2. Back up personal files and charge the player first.

1. Select Innioasis / Y1 / Type A in Updater CE.
2. Choose Install from file and select this ZIP. Keep the package zipped.
3. Start Install / Restore, then connect the powered-off Y1 when prompted.
4. Wait for explicit completion; do not unplug while writing. Afterwards disconnect and hold Center to start.
5. If Android asks for a Home app, select Y1 Theme Player / Always.

Only LOGO and ANDROID are selected. Do not add partitions or formatting options. Put music under Music using Settings / USB file transfer. Later player APKs can be copied into Updates and selected under Settings / Update player. Full English/Japanese instructions are in the companion release notes.

## 日本語

純正3.1.2／Android 4.2.2ベースのInnioasis Y1 Type A用音楽FWです。Type B・Y2には使用しないでください。事前に個人ファイルをバックアップし、本体を充電してください。

1. Updater CEでInnioasis / Y1 / Type Aを選びます。
2. ファイルからインストールでこのZIPを指定します。解凍しません。
3. インストール／復元を開始し、案内時に電源OFFのY1を接続します。
4. 完了まで抜かず、終了後にUSBを外して中央ボタン長押しで起動します。
5. HOME選択が出たらY1 Theme Player / 常に使用を選びます。

対象はLOGOとANDROIDのみです。書込み対象やフォーマットを追加しないでください。音楽は設定 / USBファイル転送からMusicへ、後のアプリ更新はUpdates内APKを設定 / アプリを更新から選択します。詳細は同梱の英日リリースノートを参照してください。
